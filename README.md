Customer Churn Analysis

Project Overview

This project analyzes customer churn using the IBM Telco Customer Churn dataset. The goal is to understand customer retention and identify patterns associated with customers leaving the service.

Dataset

- Total records: 7,043 customers
- Total columns: 21
- Target column: Churn

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Power BI

Data Cleaning

- Checked missing values.
- Converted "TotalCharges" from text to numeric.
- Replaced 11 blank "TotalCharges" values with 0.
- Saved the cleaned dataset as a separate CSV file.

Exploratory Data Analysis

Analyzed:

- Customer churn distribution
- Churn by contract type
- Churn by internet service
- Churn by payment method
- Churn by tech support
- Average tenure by churn status

Key Findings

- Total customers: 7,043
- Churned customers: 1,869
- Churn rate: 26.54%
- Retained customers: 5,174
- Month-to-month contract customers had a higher churn rate than customers on longer contracts.

Dashboard

Created an interactive Power BI dashboard with KPI cards and visualizations to explore customer churn patterns.

Project Files

- Original dataset
- Cleaned dataset
- Python analysis script
- Charts folder
- Power BI dashboard

Conclusion

This project demonstrates data cleaning, exploratory data analysis, visualization, and dashboard creation to understand customer churn.
